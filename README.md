# Pixel Art Studio

Editor de pixel art con capas, animacion y galeria. Creado en compania de mis hijos, solo por diversion.

## Stack

- Svelte 5 (runes)
- Vite
- Tailwind CSS v4
- vite-plugin-pwa

## Desarrollo

```bash
nvm use
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Se despliega automaticamente a GitHub Pages via GitHub Actions al hacer push a `main`.
