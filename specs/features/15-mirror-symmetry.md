# Feature 015: Mirror Symmetry

**Status:** Implemented
**Spec written:** 2026-09-08
**Tests:** `tests/unit/stores/editor.test.js`, `tests/unit/components/Toolbar.test.js`
**Objective:** `specs/project/objective.md`
**Related issue:** [#41](https://github.com/cristianmolinag/pixel-art/issues/41)
**Depends on:** F03 Drawing Tools (#5, implemented; eyedropper extension #40)

## User Story Summary

> As a **pixel artist**, I want to draw with horizontal and/or vertical symmetry so I can create balanced sprites, faces, ships, and characters faster.

## Prioritized User Stories

### User Story 1: Toggle horizontal mirror (Priority: P1)

The toolbar MUST offer a horizontal mirror toggle. When active, every brush, eraser, and line stroke is reflected across the vertical center line of the canvas.

### User Story 2: Toggle vertical mirror (Priority: P1)

The toolbar MUST offer a vertical mirror toggle. When active, every brush, eraser, and line stroke is reflected across the horizontal center line of the canvas.

### User Story 3: Combine both mirrors (Priority: P1)

When both toggles are active, a single stroke MUST paint up to four symmetrical pixels: the original, the horizontally mirrored, the vertically mirrored, and the diagonally mirrored pixel.

### User Story 4: Symmetry is optional (Priority: P1)

When both toggles are inactive, drawing MUST behave exactly as before.

### User Story 5: Line preview reflects symmetry (Priority: P2)

While using the line tool, the live preview MUST show the mirrored line(s) in real time.

## Functional Requirements

- **FR-001:** The system MUST provide a toggle for horizontal mirror symmetry in the toolbar.
- **FR-002:** The system MUST provide a toggle for vertical mirror symmetry in the toolbar.
- **FR-003:** Horizontal mirror symmetry MUST reflect coordinates across the vertical center line at `(cols - 1) / 2`.
- **FR-004:** Vertical mirror symmetry MUST reflect coordinates across the horizontal center line at `(rows - 1) / 2`.
- **FR-005:** Brush strokes MUST paint all unique cells generated by the active mirrors.
- **FR-006:** Eraser strokes MUST erase all unique cells generated by the active mirrors.
- **FR-007:** Line strokes MUST draw the original line and each reflected line required by the active mirrors.
- **FR-008:** Line preview MUST render the original preview line and each reflected preview line required by the active mirrors.
- **FR-009:** The active mirror toggles MUST be visually marked.
- **FR-010:** Drawing MUST behave identically to the pre-symmetry implementation when both toggles are inactive.

## Success Criteria

- **SC-001:** A user can toggle horizontal mirror and see brush strokes reflected across the vertical center.
- **SC-002:** A user can toggle vertical mirror and see brush strokes reflected across the horizontal center.
- **SC-003:** A user can enable both mirrors and see up to four symmetrical pixels from a single stroke.
- **SC-004:** A user can disable both mirrors and observe unchanged behavior.
- **SC-005:** The line tool preview reflects the active mirrors while dragging.
- **SC-006:** The mirror toggles are accessible and visually indicate their state.
- **SC-007:** The user-story scenarios are covered by unit tests.

## Scope / Non-goals

- Fill tool symmetry is out of scope.
- Diagonal symmetry (other than the result of combining horizontal and vertical) is out of scope.

## Assumptions

- The canvas uses the same `cols` and `rows` for the horizontal and vertical dimensions.
- Symmetry is computed from integer cell coordinates.
- Undo/redo treats each stroke as a single action, regardless of how many symmetrical pixels are painted.

## Decisions

- Mirror state lives in `editor.svelte.js` as `mirrorX = $state(false)` and `mirrorY = $state(false)`.
- Reflection uses `cols - 1 - x` for horizontal mirror and `rows - 1 - y` for vertical mirror.
- A helper `mirroredCells(x, y)` returns the unique set of cells to modify based on the active toggles.
- `paintPixel`, `erasePixel`, and `drawLine` apply symmetry internally so `PixelCanvas.svelte` keeps the same call sites.
- `PixelCanvas.svelte` uses the same reflection logic for line preview by reusing `editor.model` dimensions and computing mirrored end points.
- Toolbar toggles use icon buttons from `lucide-svelte` with accessible English labels.
